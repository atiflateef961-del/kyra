# Surface primitives

Import `styles/tokens.css` and `styles/surfaces.css` before using these React
components. They accept standard HTML attributes and an optional `className`.

- `GlassCard`: elevated or flat translucent content surface.
- `GlassPanel`: padded standard, muted, or strong glass surface.
- `LiquidPanel`: a softly layered panel with blue, aqua, or pink accent.
- `AnimatedBorder`: a decorative, reduced-motion-aware border wrapper.
- `FloatingPanel`: a fixed-position semantic `<aside>` for transient UI content.
- `NeumorphicButton`: a native button with neutral, primary, and danger tones.
- `NeumorphicToggle`: a controlled, accessible native-button switch.
- `GestureControl`: a controlled gesture-configuration toggle; it does not
  detect gestures or persist settings.

These primitives do not fetch data, request permissions, or imply agent state.
